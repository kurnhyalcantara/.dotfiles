
# 🧰 Dotfiles — macOS Developer Environment - My personal preference (Kurniawan)

Repository ini berisi konfigurasi **ZSH (pure)**, **Powerlevel10k**, **tmux**, **Neovim + LazyVim**, dan **Git**  
yang dapat di-setup **secara otomatis** pada laptop baru / fresh install macOS.

> 🎯 Target: *clone once → run bootstrap → DONE*

---

## 🚀 Quick Start (One-Line Bootstrap)

```sh
curl -fsSL https://raw.githubusercontent.com/kurnhyalcantara/dotfiles/main/bootstrap.sh | zsh
```
